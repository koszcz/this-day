# This Day

*This Day* is a 2.5D survival game that runs in your browser. It uses three.js, a fixed isometric camera, and low-poly art made in code.

## About this project

This project is a capability test of Claude Sonnet 5.5. Claude Sonnet 5.5 wrote the game code, tests, and documents. The goal was to see how well the model builds a complete game with little human help.

## Run it

You need [Bun](https://bun.sh).

1. Run `bun install`.
2. Run `bun dev`.
3. Open http://localhost:5174.

## Check your changes

- Run `bun run check` for types, file size, and test coverage rules.
- Run `bun test` for the tests.
